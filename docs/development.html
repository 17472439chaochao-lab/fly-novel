📋 1. 项目概览

FlyNovel 是一款基于 Electron 的跨平台桌面小说阅读器，核心特性包括：

  • 书源兼容：导入 Legado（阅读 App）文本书源，支持 CSS / XPath / JSONPath 规则解析
  • 多源搜索：多书源并发搜索，流式返回结果，支持书源匹配质量学习排序
  • 本地阅读：打开本地 TXT / EPUB 文件，自动编码检测与章节切分
  • 离线缓存：章节正文存入 SQLite，断网可读已缓存章节；支持整本缓存与导出 TXT
  • 阅读体验：纸感 / 护眼 / 夜间三主题，系统字体选择，字号 / 行距 / 版心可调
  • 实用功能：老板键一键隐藏、自动滚屏、正文净化规则、护眼/久坐提醒、版本更新检查
  • 贴心细节：书架显示上次阅读时间、侧栏底部每 5 分钟轮换阅读短句

🏗️ 2. 架构设计

FlyNovel 采用 Electron 标准的三进程架构，严格遵循 contextIsolation + preload 桥接安全模型：

┌─────────────────────────────────────────────────────┐
│                    Electron App                      │
│                                                      │
│  ┌──────────────┐   IPC    ┌──────────────────────┐ │
│  │  Main Process │◄────────►│  Renderer Process    │ │
│  │               │  handle  │                      │ │
│  │  · 窗口管理    │  send    │  React UI            │ │
│  │  · SQLite DB  │          │  · ShelfView         │ │
│  │  · 书源引擎    │          │  · SearchView        │ │
│  │  · HTTP 请求   │          │  · ReaderView        │ │
│  │  · 本地文件    │          │  · SourcesView       │ │
│  │  · 全局快捷键  │          │  · SettingsView      │ │
│  └──────┬───────┘          └──────────▲───────────┘ │
│         │                             │              │
│         │         ┌───────────────────┘              │
│         │         │ contextBridge                     │
│         │         ▼                                  │
│         │   ┌─────────────┐                          │
│         └──►│  Preload    │◄─── window.fly API       │
│             │  (isolated) │                          │
│             └─────────────┘                          │
└─────────────────────────────────────────────────────┘

核心设计原则

  • 进程隔离：主进程负责所有 Node.js / 原生能力（数据库、HTTP、文件系统），渲染进程仅通过 window.fly API 调用，无法直接访问 Node
  • 共享类型：src/shared/ 目录的代码同时被主进程和渲染进程引用，确保类型一致性
  • 单一 SQLite：所有持久化数据（书源、书架、设置、章节缓存）存储在同一个 fly-novel.sqlite 文件中
  • 事件驱动通信：耗时操作（搜索、测试、缓存）通过 ipcMain.handle + sender.send 进度事件实现流式更新

数据流示意

▼

▼

⚙️ 4. 主进程模块

4.1 入口与窗口管理 — src/main/index.ts

主进程核心入口，负责应用生命周期与所有基础设施初始化：

  • 应用初始化：设置应用名 FlyNovel，固定 userData 目录为 fly-novel（避免 productName 变更导致数据迁移问题），配置系统「关于」面板
  • 窗口管理：createWindow() 创建主 BrowserWindow，配置 titleBarStyle: 'hiddenInset'、红绿灯位置 {x:16,y:16}，持久化窗口边界到偏好设置，拦截新窗口打开（转发给系统浏览器）
  • 主题管理：applyAppTheme() 按阅读主题（paper / green / night）设置 nativeTheme 和窗口背景色
  • 应用菜单：setupAppMenu() 按平台（macOS / Win / Linux）构建中文化菜单
  • 老板键：toggleBossVisibility() 隐藏 / 显示主窗口（同时向渲染进程广播 app:boss-visibility 事件），registerBossKeyFromPrefs() 注册全局快捷键
  • IPC 注册：registerIpc() 注册全部 ipcMain.handle 通道
  • 生命周期：app.whenReady() 初始化数据库 → 确保默认配置 → 注册 IPC → 创建窗口；before-quit 关闭数据库；will-quit 注销全局快捷键

4.2 数据库层 — src/main/db.ts

使用 better-sqlite3 管理单一 SQLite 数据库文件，路径为 {userData}/fly-novel.sqlite。

数据库特性：WAL 模式（Write-Ahead Logging）、外键约束开启、同步 API 调用。

迁移机制：

  • migrateFromElectronStore() — 从旧版 fly-novel.json（electron-store 格式）迁移书源、书架、设置、搜索历史、章节缓存
  • migrateFromLegacyChaptersSqlite() — 从旧版独立 chapters.sqlite 迁移章节缓存

封装所有业务数据的 CRUD 操作，是 IPC handler 与数据库之间的业务逻辑层：

4.5 书源引擎 — src/main/legado/

4.5.1 引擎入口 engine.ts

实现 Legado 书源的完整解析流程，核心函数：

  • searchBooks(source, key, page) — 搜索：解析 URL 模板 → HTTP 请求 → 列表规则提取 → 逐条字段提取
  • getBookInfo(source, bookUrl) — 详情：抓取详情页，按 ruleBookInfo 提取书名/作者/简介/目录URL 等
  • getChapterList(source, tocUrl) — 目录：循环抓取目录页（最多 30 页），按 ruleToc.chapterList 提取章节列表，支持 nextTocUrl 分页
  • getContent(source, chapterUrl) — 正文：循环抓取正文页（最多 20 页，去重防循环），支持 sourceRegex 预提取、replaceRegex 正则替换
  • normalizeSources(input) — 规范化导入的书源 JSON（过滤非文本书源）
  • testSource(source, keyword) — 实测书源可用性，返回 ok / message / found / respondMs / structuralOk
正文解析特殊处理：正文规则强制改为 @html 提取以保留 <br> / <p> 结构，再通过 htmlToNovelText() 转换为以空行分隔的小说段落正文。

4.5.2 HTTP 请求层 http.ts

  • fetchText(url, options) — 基于 fetch 的 HTTP 请求，使用 iconv-lite 按检测字符集解码，支持超时（默认 15s）、POST body、自定义 headers
  • detectCharset(contentType, buf) — 从 Content-Type 头或 HTML meta 标签检测字符集
  • normalizeCharset(c) — 规范化中文编码别名（gb2312 / gbk / gb18030 统一为 gbk）
  • parseRequestUrl(raw, vars) — 解析 Legado URL 模板：替换 {{key}} / {{page}} 等 mustache 变量，解析 {{(expr)}} 表达式，识别 ,{...} JSON 选项后缀
  • resolveUrl(base, path) — 相对路径转绝对 URL

4.5.3 规则分析器 analyzeRule.ts

支持 Legado 书源的多种规则语法，是引擎的核心：

能力函数说明
模式检测detectMode(rule, content)按前缀推断：@js: → Js；$. → Json；// → XPath；否则 → CSS
规则拆分parseRuleParts(rule)按 ## 拆分选择器与正则替换段，按 @ 拆分选择器与取值类型
CSS 解析analyzeCss()使用 cheerio，支持 Legado 特殊语法：text. 文本匹配、id./class. 简写、索引语法 .item.0
XPath 解析analyzeXPath()使用 @xmldom/xmldom + xpath 库
JSON 解析analyzeJson()使用 jsonpath-plus
列表提取getElements(content, rule)按列表规则返回元素 HTML 片段数组
单值提取getString() / getStringList()支持 || 备选规则、{{rule}} mustache 插值
正则链applyRegexChain()按 ## 拆出的 pattern/replacement 对执行链式替换
取值类型（@ 后缀）：@text 纯文本 · @html 内部 HTML · @href 链接 · @src 图片地址 · @ownText 直接文本（不含子元素）· @textNodes 所有文本节点

4.6 本地文件解析 — src/main/localBooks/

4.6.1 导入入口 importLocal.ts

  • importLocalBookDialogAsync(win) — 弹出文件选择对话框（支持 .txt / .epub）
  • importLocalBookAsync(filePath) — 根据扩展名分派到 TXT 或 EPUB 解析
  • localBookId(filePath) — SHA1 哈希生成 local: 前缀的稳定 ID
  • persistLocalBook() — 将章节写入缓存库并 upsert 到书架

4.6.2 TXT 解析 txtSplit.ts

  • 编码检测：decodeTxtBuffer(buf) — BOM 检测（UTF-8 / UTF-16LE / UTF-16BE）+ 多编码候选打分（utf-8 / gb18030 / gbk / gb2312 / big5），按 CJK 字符比例、替换符数量等打分选最优
  • 章节切分：splitTxtChapters(raw, fallbackTitle) — 正则启发式识别章节标题行（第X章 / 序章 / Chapter N / 数字序号），强标题不足 3 个时回退到全部标题；命中过少时按 12000 字体积切分

4.6.3 EPUB 解析 epubParse.ts

  • parseEpubBuffer(buf, fallbackTitle) — 使用 JSZip 解压，解析 META-INF/container.xml 找到 OPF，提取书名 (dc:title)、作者 (dc:creator)，按 spine 顺序读取章节 HTML
  • loadTocTitles() — 从 EPUB3 nav XHTML 和 EPUB2 NCX 加载 href→标题映射
  • extractCoverDataUrl() — 从 OPF manifest 提取封面图并转 data URL（支持 cover-image 属性、meta name=cover、文件名含 cover 三种策略）

4.6.4 TXT 导出 exportTxt.ts

  • exportShelfBookToTxt(bookId, win, opts) — 将书架在线书籍导出为 TXT：先检查缓存，缺失章节按书源拉取（并发），生成带署名的格式化 TXT 文件（BOM + UTF-8）

🔗 5. Preload IPC 桥接

文件：src/preload/index.ts

通过 contextBridge.exposeInMainWorld('fly', api) 暴露结构化 API 对象。安全配置：contextIsolation: true、nodeIntegration: false。

API 结构

window.fly = {
  // 应用级
  getState(),                    // 获取应用全局状态
  getVersion(),                  // 获取版本号
  checkUpdate(),                 // 检查 Gitee 更新
  openExternal(url),             // 用系统浏览器打开外链

  // 书源管理
  sources: {
    list(),                      // 列出全部书源
    importFile(),                // 从本地 JSON 导入
    importUrl(url),              // 从 URL 订阅导入
    toggle(url, enabled),        // 启用/禁用
    remove(url),                 // 删除
    update(oldUrl, source),      // 更新/替换
    test(url, keyword?),         // 单测
    testAll(keyword?, urls?),    // 批量测试
    onTestProgress(cb),          // 监听测试进度
    removeInvalid(),             // 删除无效书源
  },

  // 书籍与搜索
  books: {
    search(keyword),             // 多书源并发搜索
    onSearchProgress(cb),        // 监听搜索进度
    onSearchPartial(cb),         // 监听中间结果（流式）
    history(),                   // 搜索历史
    clearHistory(),              // 清空历史
    removeHistory(keyword),      // 删除单条历史
    info(origin, bookUrl),       // 获取书籍详情
    toc(origin, tocUrl),         // 获取章节目录
    content(origin, chapterUrl, bookId?),  // 获取正文（优先缓存）
    cachedUrls(bookId),          // 列出已缓存 URL
    preload(origin, bookId, urls[]),       // 预加载章节
  },

  // 书架
  shelf: {
    list(),                      // 书架列表
    upsert(book),                // 插入/更新
    patchProgress(id, patch),    // 仅更新进度
    remove(id),                  // 移除（含清缓存）
    importLocal(),               // 导入本地 TXT/EPUB
    updateAll(),                 // 批量更新
    cacheBook(id),               // 整本缓存
    cancelCache(id),             // 取消缓存
    exportTxt(id),               // 导出为 TXT
    cacheStatus(id),             // 查询缓存状态
    onUpdateProgress(cb),        // 监听更新进度
    onCacheProgress(cb),         // 监听缓存进度
  },

  // 设置
  settings: {
    get(),                       // 获取阅读器设置
    save(settings),              // 保存设置
    addPurify(rule),             // 添加净化规则
    removePurify(rule),          // 删除净化规则
  },

  // 字体与偏好
  fonts: { list() },             // 系统字体列表
  prefs: { get(), save(patch) }, // 应用偏好

  // 老板键可见性
  onBossVisibility(cb),          // 订阅老板键隐藏/显示状态
}
所有 on* 方法返回取消订阅函数，用于 React useEffect 清理，避免内存泄漏。

🗄️ 8. 数据库设计

单一 SQLite 文件：{userData}/fly-novel.sqlite，WAL 模式，外键约束开启。

表结构

表名主键字段用途
meta key TEXT key TEXT PK, value TEXT NOT NULL 元数据（迁移标记等）
settings key TEXT key TEXT PK, value TEXT NOT NULL 配置键值对（reader / app）
sources book_source_url TEXT book_source_url TEXT PK, data TEXT, sort_order INTEGER 书源（JSON 存储）
shelf_books id TEXT id TEXT PK, data TEXT, sort_order INTEGER, updated_at INTEGER 书架书籍（JSON 存储）
search_history keyword TEXT keyword TEXT PK, searched_at INTEGER 搜索历史
chapters (book_id, chapter_url) book_id TEXT, chapter_url TEXT, chapter_index INTEGER, title TEXT, content TEXT NOT NULL, cached_at INTEGER 章节正文缓存

索引

idx_chapters_url    ON chapters(chapter_url)
idx_chapters_book   ON chapters(book_id)
idx_shelf_sort      ON shelf_books(sort_order, updated_at DESC)
idx_sources_sort    ON sources(sort_order)
idx_history_time    ON search_history(searched_at DESC)
存储策略：书源和书架书籍以 JSON 字符串存储在 data 列中，便于 schema 演进（增减字段无需 ALTER TABLE），但牺牲了字段级查询能力。章节缓存则使用独立列存储，便于按 book_id / chapter_url 高效查询。

书源排序算法

  • speedTagFromRespondMs(ms) — <500ms=turbo, <1500=excellent, <2000=good, else slow
  • sourceMatchStrength(s, shelfCountByOrigin) — 学习分 (flyMatchScore) + 书架使用加成（每本 +18，上限 75，总上限 100）

❓ 12. 常见问题

Q: 启动时崩溃（SIGSEGV）？

A: 通常是 better-sqlite3 原生模块与 Electron ABI 不匹配。执行 npx @electron/rebuild -f -w better-sqlite3 重建。确认使用 better-sqlite3@11.x（兼容 Electron 34）。

Q: 菜单栏显示 "Electron" 而非 "FlyNovel"？

A: 已通过 scripts/ensure-electron.js 将 Electron.app 重命名为 FlyNovel.app 并修改 Info.plist。改名后需完全退出应用再启动。

Q: 书源 / 书架突然空了？

A: 数据固定在 Application Support/fly-novel 目录。若曾因 productName 变更落到 FlyNovel 空目录，启动新版后会自动迁移回原目录。

Q: 某些书源搜索无结果？

A: 书源可能需要 @js 规则、WebView 渲染或登录认证，这些属于暂不支持的复杂书源类型。可用 scripts/smoke-rules.ts 测试规则解析是否正常。

Q: 如何在 Git 中忽略不需要的文件？

A: .gitignore 已配置忽略 node_modules/、out/、release/、本地数据库与系统文件。请勿提交这些目录。

Q: Windows 打包需要在 Windows 上进行吗？

A: 推荐在 Windows 机器上打包 Windows 版本。交叉打包可能受限于代码签名与部分工具链。
